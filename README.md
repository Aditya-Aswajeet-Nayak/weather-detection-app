# Weather Detection App 🌤️

A desktop weather application built with Python and PyQt5.

## Features
- Enter city name
- Fetch live weather using OpenWeather API
- Displays temperature
- Shows weather emoji
- Clean custom-styled GUI

## Tech Stack
- Python
- PyQt5
- Requests
- OpenWeatherMap API

## Run locally
```bash
pip install -r requirements.txt
python main.py
